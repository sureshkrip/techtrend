# psycopg 3 paramstyle reference (the single load-bearing dialect fact):
#   - SQLite positional  `?`          -> psycopg  `%s`
#   - SQLite named       `:name`      -> psycopg  `%(name)s`
#   - a LITERAL `%` in SQL text (e.g. `LIKE 'collect:%'`) MUST be doubled to
#     `%%` when the statement carries any params, or passed as a bound param.
#   - conn.execute(sql, params) returns a Cursor; .fetchall()/.fetchone()
#     work exactly as with sqlite3. dict_row rows support row["col"] and
#     dict(row) (string keys only — NOT integer indexing).
</context>
