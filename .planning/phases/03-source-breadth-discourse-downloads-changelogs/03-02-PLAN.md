<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tracked.toml -> config loader | Curated, owner-edited source lists (never user input at runtime) cross into the app via pydantic validation |
| collector -> public third-party API | Unauthenticated outbound GET to Algolia/npm/pypistats; no secret leaves the process |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03 | Information Disclosure | http.py GitHub token | high | mitigate | New public client performs no token lookup and attaches no Authorization header; GITHUB_TOKEN literal stays confined to http.py (T-01-12); GitHub client's fail-loud token requirement untouched |
| T-03-04 | Denial of Service | outbound retries against public APIs | medium | mitigate | is_retryable_public retries only 429/5xx and never loops on a permanent 4xx (RESEARCH Pitfall 3); daily cadence self-limits request volume |
| T-03-05 | Tampering (SSRF) | changelog feed URLs | low | accept | Feed URLs are curated in tracked.toml, never accepted from a request param in v1; revisit if a user-facing "add feed" action is ever added |
</threat_model>
