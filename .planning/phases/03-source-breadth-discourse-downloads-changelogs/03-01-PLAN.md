Purpose: This is D3-5 deviation touch #1 — the ONLY scorer change allowed in this phase. Without it, Wave-2 collectors would produce dashboard-invisible entities.
Output: A source-agnostic scoring path + a regression test proving a non-'stars' metric ranks.
</objective>
