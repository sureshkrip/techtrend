<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SQLite → rendered HTML | Externally-sourced strings (repo name, description, homepage URL) originate at GitHub and cross into a browser-rendered page here |
| browser → FastAPI | The `sort` query parameter is attacker-controllable in principle and reaches query construction |
| filesystem → HTTP | `StaticFiles` serves a directory over HTTP |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Tampering | `partials/table.html` rendering `full_name` / `homepage` from GitHub | high | mitigate | Jinja2 autoescaping is on by default for `.html` via `Jinja2Templates`; the `safe` filter is forbidden on any externally-sourced field, enforced by an acceptance-criteria grep |
| T-01-06 | Tampering | `query_ranked` ORDER BY built from the `sort` parameter | high | mitigate | `sort` maps through a fixed allow-dict to fixed ORDER BY fragments; unrecognized values fall back to velocity. No string concatenation of request input into SQL |
| T-01-07 | Elevation of Privilege | Dashboard triggering a write or a pipeline run | medium | mitigate | `queries.py` contains no INSERT/UPDATE/DELETE and `app.py` never imports `techtrend.ingest`; both enforced by acceptance-criteria greps and by `test_dashboard_never_writes` |
| T-01-08 | Information Disclosure | Framework traceback leaking file paths on a DB read failure | medium | mitigate | `sqlite3.Error` is caught in the route and rendered as the UI-SPEC's DB-unreadable copy |
| T-01-09 | Information Disclosure | `StaticFiles` mount exposing unintended files | low | mitigate | The mount is rooted at `techtrend/web/static` only, which holds exactly two files |
| T-01-10 | Spoofing | No authentication on the dashboard | low | accept | Single local user by design; the server binds to `127.0.0.1` and ASVS L1 has no auth requirement for a host-local single-user tool with no account surface |

**Canon-referral breadcrumb:** stored XSS is canon OWASP — the Jinja2 autoescaping control above is recorded as a mitigation, but the general class is covered by `/gsd-secure-phase`; not minted as a bespoke prohibition here.
</threat_model>
