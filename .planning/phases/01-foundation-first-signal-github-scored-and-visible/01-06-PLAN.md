## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → FastAPI | The `sort` query parameter and any other request input cross into query construction |
| SQLite → rendered HTML | Repo names, descriptions, and resolved URLs originate at GitHub and reach the browser |
| run_manifest error_detail → rendered HTML | Exception text, potentially containing file paths, reaches a user-visible banner |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-29 | Tampering | `sort` parameter reaching ORDER BY | high | mitigate | `SORT_KEYS` is a fixed allow-dict of parameter value to fixed SQL fragment; unrecognized input falls back to velocity. Request input is never concatenated into SQL. Covered by a passing test |
| T-01-30 | Tampering | Crafted repo name, description, or docs URL rendered in the table | high | mitigate | Jinja2 autoescaping on all `.html` templates; the `safe` filter is absent, enforced by an acceptance-criteria grep. URLs are rendered as `href` values and never fetched or executed by the app |
| T-01-31 | Information Disclosure | `error_detail` leaking file paths or internals into the health banner | high | mitigate | Truncated to 120 characters before entering the render context; the full text is never passed to the template and stays in the log file only |
| T-01-32 | Information Disclosure | A framework traceback on a DB read failure | medium | mitigate | `sqlite3.Error` is caught and rendered as the Copywriting Contract's database-unreadable copy; verified manually in checkpoint step 9 |
