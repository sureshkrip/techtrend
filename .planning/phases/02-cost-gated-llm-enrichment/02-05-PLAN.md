## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| enrichments table -> HTML | LLM-generated summary text (which may echo attacker README content) is rendered to the browser |
| query params -> SQL | the ?section= value crosses into query_ranked |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-13 | Elevation of Privilege | stored XSS from LLM summary echoing README content | high | mitigate | Jinja2 default autoescape (already relied on for full_name/docs_url); acceptance grep asserts no |safe on summary_line_1/summary_line_2/section — do not introduce the codebase's first |safe |
| T-02-14 | Tampering | ?section= injection into query_ranked | medium | mitigate | section bound as a SQL parameter (:section), never interpolated — same discipline as SORT_KEYS/query_ranked (V5) |
| T-02-15 | Denial of Service | enrichment failure removing a ranked row | high | mitigate | LEFT JOIN keeps every eligible row; unenriched rows render honest fallbacks (D-10) — the dashboard never hides already-ranked data |
</threat_model>
